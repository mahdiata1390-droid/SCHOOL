# SCHOOL

اپلیکیشن اندرویدی مدیریت کلاس برای معلم.

کاملاً آفلاین؛ بدون سرور، حساب، API یا اینترنت در زمان استفاده.
اطلاعات با SQLite روی خود دستگاه ذخیره می‌شود.
شامل افزودن، جستجو، رتبه‌بندی، حذف، افزایش/کاهش امتیاز، بازخورد لمسی و حالت روشن/تیره است.

GitHub Actions با هر push روی main یک APK release می‌سازد.
